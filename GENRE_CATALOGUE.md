# On-demand genre catalogue

Independent and non-AIR radio first. Only four AIR services retained for Chennai, Gangtok, Kurseong and national classics. Foreign Nepali stations serve language interest, not local Sikkim news. Loaded only on a genre-filter click; default presets stay separate. Directory stream addresses are researched, not live-playback verified.

The five keys load this file only on first click. Language and genre filters combine; clearing them restores the existing default list. Nepali services appear in NEWS / MUSIC selections. No media is preloaded by loading the catalogue.

## Limits

Researched 17 November 2026. All catalogue stream URLs use HTTPS. Playback, redirects, CORS and regional availability could not be live-tested here. Third-party directories are evidence for addresses, not proof of broadcaster authorization or continuous uptime. Nepal-based stations are not described as Sikkim local broadcasters. Radio Misty is not included because a dependable direct live feed was not established. No new dependencies.
